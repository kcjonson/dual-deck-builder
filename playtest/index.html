Wasteland Wheels

A roguelike deckbuilder about running two vehicles at once, each with its own driver and deck. These are early alpha builds for Windows and macOS: download the one for your machine, unzip it, and run it.

How to run

The builds aren't signed yet, so Windows and macOS warn about them the first time you open one. The steps below get past the warning once; after that the game opens normally.

Windows 10 or 11, 64-bit
  1. Right-click the zip and choose Extract All. Don't run the game from inside the zip.
  2. Open the extracted folder and double-click the game's .exe.
  3. If Windows says Windows protected your PC, click More info, then Run anyway.

Saves live in %LOCALAPPDATA%\Bear Cave Interactive\Wasteland Wheels\saves; paste that into File Explorer's address bar to open it. Deleting the game's folder leaves them alone.

macOS 14 or later

Take Apple silicon for a Mac with an M-series chip and Intel for an older one; Apple menu > About This Mac says which.

  1. Double-click the zip to unzip it, if Safari hasn't already.
  2. Open the game. macOS says it couldn't verify the app is free of malware; click Done.
  3. Open System Settings > Privacy & Security, scroll down to the message about Wasteland Wheels, and click Open Anyway. Confirm with your password, then click Open.

On macOS 14, Control-click the app and choose Open instead of steps 2 and 3.

If macOS says the app is damaged, or Open Anyway never shows up, open Terminal, type xattr -dr com.apple.quarantine (with the space at the end), drag the unzipped folder onto the Terminal window, press Return, and open the game again.

Saves live in ~/Library/Application Support/Bear Cave Interactive/Wasteland Wheels Data/saves; in Finder, choose Go > Go to Folder and paste it. Deleting the game leaves them alone.
