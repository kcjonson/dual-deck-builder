# UI art direction canvas sources

The source of the "Wasteland Wheels UI Concept" design canvas, checked in so the work outlives the hosted canvas. Each `.dc.html` file is one artboard in the canvas's Design Component format, and `canvas.json` is the layout. They need the canvas runtime (`support.js`) to render as-is; the PNGs one folder up are the rendered boards.

The files are named for where they sat on the canvas: `Final*` is the playtest direction (not final, despite the name), `Atlas*`, `Kit*`, and `Form*` are directions A, B, and C, `Main`, `Weathered`, and `Worn` are the mood boards, `Materials` is materials and marks, `WearStandards` is the wear rules, and `Lamplight` is the rejected night look. See [UI Art Direction](../../../specs/UI%20Art%20Direction.md) and [ui-art-direction.md](../../../AI_TECHNICAL_DECISIONS/ui-art-direction.md).
