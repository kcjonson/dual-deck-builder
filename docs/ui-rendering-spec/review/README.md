# Review reports

Independent reviews of the first draft of the specification (2026-09-07), each written from one lens with instructions to challenge rather than confirm. Findings are numbered per report (U1, I1, G1, W1, C1) and their resolutions are recorded in chapter 17 of the specification; the reports themselves are kept verbatim.

| File | Lens |
|---|---|
| [01-graphics-engineer.md](01-graphics-engineer.md) | Real-time graphics: ordering model soundness, clipping, shading, text, coordinates, the WebGL2 backend chapter, with web verification of technical claims |
| [02-ui-architect.md](02-ui-architect.md) | UI framework design: object model, input and focus, layout, styling, catalog, snapshot and lint, with a worked authoring example of the combat screen |
| [03-worldsim-maintainer.md](03-worldsim-maintainer.md) | Provenance: every "worldsim does X" statement checked against the C++ source; the chapter 16 gap list validated; the spec's deviations from worldsim critiqued from that project's point of view |
| [04-implementer.md](04-implementer.md) | Feasibility in the sibling TypeScript codebase: migration map, under-specification for a card game, tooling fit, the first three pull requests, corrections to chapter 14's scoring |
| [05-consistency-editor.md](05-consistency-editor.md) | Cross-chapter contradictions, dangling rule references, terminology, checklist mismatches, house style |

The first attempt at reports 01, 03, and 05 was cut short by a rate limit; they were rerun against the second draft and resolved into drafts 3 and 4.
